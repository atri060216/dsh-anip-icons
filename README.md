# dsh-anip-icons

ANIP 格式通知图标资源包（72x72 画布、64px 图形），供 ColorOS Notify 等支持 ANIP 自定义来源的模块使用。

内容 = DSH 白化版 744 条 + AndroidNotifyIconAdapt 补充 55 条。

## 自定义地址

https://cdn.gh-proxy.org/https://github.com/atri060216/dsh-anip-icons/releases/latest/download

备用（直连）：https://github.com/atri060216/dsh-anip-icons/releases/latest/download

## 说明

- com.huawei.welink 使用 com.huawei.works 的图形
- com.tencent.mobileqq 不包含（沿用官方主源图标）
